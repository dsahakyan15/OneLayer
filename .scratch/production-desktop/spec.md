Полная спецификация не выполнена. Реализованы ограниченные lab/web/backend срезы; ни один из них не закрывает весь пользовательский pipeline установленного launcher. [Актуальная матрица](../../docs/implementation-status-2026-10-02.md) определяет, что работает и что осталось; [личное ревью](evidence/launcher-usage-pipeline-review-2026-10-02.md) фиксирует блокеры.

## Ограничения

- «Все лица» означает всех авторизованных внутренних участников в собственном scope, а не публичный доступ или одинаковые права.
- Tauri 2 — предлагаемая реализация, подтверждаемая spike; desktop-продуктовая форма уже задана пользователем.
- По решению пользователя от 2026-09-24 первая production-платформа — Linux, целевая конфигурация первого выпуска — Linux Mint 22.1 x86_64 на его текущем рабочем месте. Windows/macOS отложены; поддержка других Linux-дистрибутивов требует отдельной приемки.
- Production secrets, реальные данные, mainnet deployment и внешние отправки не разрешаются одним наличием этого плана.
- 22–24 включают решения/проверки реальной организации; они не заменяются synthetic mock.
- Открытые решения по управляемой установке Linux, IdP/signing/storage/SLO перечислены в §12 полного плана; они блокируют только зависимые gates. Выбор Linux не заменяет платформенную приемку.
